# Orca

[Orca](https://www.onorca.dev/) is a desktop Agent Development Environment (ADE) for running multiple AI coding agents side by side. It uses isolated Git worktrees so agents can work on separate tasks without branch juggling. Supported agents include Claude Code, Codex, Cursor CLI, and OpenCode.

## Install

Download the desktop app for [macOS, Windows, or Linux](https://www.onorca.dev/download). On macOS, you can also install it with Homebrew:

```sh
brew install --cask stablyai/orca/orca
```

Use that full cask name. `brew install --cask orca` without the tap installs a different Homebrew cask.

For older versions and all release assets, see [GitHub Releases](https://github.com/stablyai/orca/releases).

## Getting started

Launch Orca, add a repository, create a worktree, and start an agent session. See the [official installation guide](https://www.onorca.dev/docs/install) and [first-session guide](https://www.onorca.dev/docs/first-session) for the complete walkthrough.
